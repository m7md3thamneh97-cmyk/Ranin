# Raneen Teaching Studio

Private repository for Raneen's conversational teaching and review prototype.

The goal is to collect reviewed demonstrations of domain decisions, dialect, wording, accent and spoken delivery—not merely voice samples.

## Current deployment scope

Owner-only staging. Employee access, automatic transcription, the AI interviewer, voice-model training and live Vapi integration are not enabled in this release. The app is not a trained conversational replica.

Source is being imported from the prepared Raneen Teaching Studio v0.1.1 staging package. Deployment is not complete until Railway reports SUCCESS and the public endpoint is checked.

No recordings, databases, access tokens or provider credentials belong in this repository.
